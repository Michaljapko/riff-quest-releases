## What is riff.quest?

[riff.quest](https://riff.quest) is a guitar practice tracker built for guitarists who want structure and real feedback, not just a metronome and a timer. The desktop app wraps the full web app in a native shell with:

- **Native ASIO / WASAPI audio input** — real hardware-level audio capture instead of the browser's mic pipeline, for lower latency and better pitch-detection accuracy.
- **Real-time pitch detection & tuner** — see what note you're actually playing, live, while you practice.
- **Guided practice sessions** — structured plans, scales, chords, and songs with progress tracking per exercise.
- **XP, streaks & leaderboards** — practice consistency turned into an actual progression system.
- **Guitar Pro (.gp) file support** — practice along to real tabs, not just static sheets.
- **Automatic background updates** — always on the latest version, no manual reinstalls.

## FAQ

**Is riff.quest free?**
Yes — the core app (practice tracking, sessions, plans, leaderboard) is free to use.

**Do I need an account?**
Yes, a free riff.quest account syncs your practice history and progress across web and desktop.

**Does the desktop app replace the web app?**
No — it's the same riff.quest app in a native shell, with added native audio support for lower-latency pitch detection. Everything else works the same as [riff.quest](https://riff.quest) in your browser.

**Where's the source code?**
This repository hosts release binaries only — riff.quest's source isn't open source. For bugs or feature requests, use the links below.

**What platforms are supported?**
Windows today, with Linux (AppImage) support on the way. macOS support is being evaluated.
